# sidequest-sandbox

A collection of smaller games and projects.

## Complete

- [x] [Who's That Pokémon](whos-that-pokemon/): guess the Pokémon from clues pulled from PokéAPI, in a Pokédex GUI or the terminal
- [x] [KTH schedule finder](schedule-finder/): finds TA labs and övningar that don't clash with your own courses on TimeEdit, and adds the ones you pick to Google Calendar
- [x] [Samsung Notes sync](samsung-notes-sync/): copies your notes as .sdocx and PDF to GitHub and Google Drive, keeping the folders and updating only changed notes
- [x] [Medvind reporter](medvind-reporter/): reports the sessions in your WORK calendar as worked hours in KTH's Medvind, never the same one twice
